# Retail Sales Analysis Dashboard using Python

## Project Overview

This project performs a comprehensive retail sales analysis using Python, Pandas, NumPy, Matplotlib, and Seaborn. The analysis integrates multiple datasets including products, customers, sales, employees, branches, and marketing campaigns to generate meaningful business insights through data visualization.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset Files

* INT_products.csv
* INT_customers.csv
* INT_sales.csv
* INT_employees.csv
* INT_branches.csv
* INT_marketing.csv

## Key Analysis Performed

### Sales Analysis

* Monthly sales trends
* Highest and lowest revenue months
* Average order value analysis
* Monthly quantity sold analysis

### Product Analysis

* Top revenue-generating categories
* Lowest revenue categories
* Product price distribution
* Price vs quantity relationship
* Brand-wise revenue analysis

### Customer Analysis

* City-wise sales contribution
* Customer age distribution
* Membership vs non-membership comparison
* Customer spending behavior
* Top 20 customers by purchase value

### Branch Analysis

* Branch revenue performance
* Average order value by branch
* Quantity sold by branch
* City-wise branch performance

### Employee Analysis

* Employee count by branch
* Role distribution
* Salary distribution
* Average salary by role

### Marketing Analysis

* Monthly advertising spend
* Campaign-wise budget allocation
* Ad spend vs sales correlation
* Branch marketing budget analysis
